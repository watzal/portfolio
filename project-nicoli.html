01

Overview

Nicoli was built from a personal frustration: jumping between browser tabs to summarise research papers, translate content, prep for interviews, and manage tasks was fragmenting focus. The goal was simple, bring all of it into one lightweight Chrome extension powered by the latest AI APIs.

The name is intentional. Derived from the Greek "Nikolaos" — victory of the people — Nicoli was designed to democratise productivity tools that typically live behind expensive SaaS paywalls.

02

The Problem

Students and knowledge workers lose an average of 23 minutes of focus every time they context-switch between tools. Reading an article, summarising it, translating a section, creating quiz questions from it, and then blocking distracting ads to stay on track, that's five separate tools, five separate tabs.

Nicoli collapses this entire workflow into a single extension that sits quietly in the corner of any page, ready when you need it.

04

Technical Architecture

Nicoli is built entirely with vanilla web technologies, no framework overhead.
The extension injects a lightweight sidebar UI and communicates with Chrome's extension APIs for tab management and ad blocking, while all AI features are handled via external API calls.

05

Challenges & Learnings

Integrating four different AI APIs with inconsistent response formats required building a unified abstraction layer. Each API had different rate limits, error modes, and latency profiles, normalising them into a single interface made the UX feel seamless.
The mock interview feature was the most technically interesting: scraping live LinkedIn job descriptions via ScrapIn, parsing the role and requirements, then generating context-specific questions with the Prompt API all in under 3 seconds end-to-end.
