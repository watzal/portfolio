01

Overview

MLMadeEasy is a no-code machine learning platform where you build ML pipelines the same way you'd draw a flowchart — by connecting nodes.
Upload a CSV, and the platform instantly analyses your data quality, flags issues, and suggests fixes. Then drag preprocessing nodes, connect a model, hit train.

The goal is to eliminate the 60–80% of ML work that is boilerplate — the repetitive data cleaning, scaling, encoding, and splitting that consumes most of the time before any actual modelling begins.

07

Challenges & Learnings

Designing a graph-based connection validation system was the most technically interesting challenge. Each node type has different valid inputs and outputs — a Train node can only come from a split, a model needs a Train connection to be valid. Encoding these rules into a clean, extensible system without a mass of if-statements required careful architecture.
The data quality scoring algorithm went through several iterations. The first version was too lenient — datasets with severe issues were scoring 80+. Introducing weighted completeness and uniqueness scoring, combined with severity-tiered recommendations, made the output genuinely useful rather than just decorative.
Building this taught me more about data preprocessing than any course. Implementing the IQR outlier detection, skewness checks, and cardinality analysis myself rather than calling a library gave me a deep intuition for what these statistics actually mean for model performance.
